# Summer26 Sandbox

This repository is the Summer 2026 sandbox for graduate CFD research, Formula SAE team work, and Python learning on macOS.

## Purpose
- Primary focus: learn and apply concepts for graduate computational fluid dynamics (CFD) research.
- Secondary focus: expand Python programming skills, macOS terminal fluency, GitHub usage, and agentic AI workflows.
- All coding should be conducted in Python unless a package or external tool explicitly requires another language.

## Repository Structure
- `.github/copilot-instructions.md` — onboarding guidance for Copilot cloud agents.
- `.gitignore` — local and environment files to exclude from version control.
- `venv/` — local Python virtual environment directory, intentionally ignored.
- `Python-Tools-Examples/` — sample Python tools, experiments, and utilities.
- `Formula-SAE/` — Formula SAE team code, simulations, notebooks, and analysis.
- `Grad-Research/` — graduate research code, CFD studies, and experiment scripts.

## Notes
- This repository is intentionally a sandbox and may evolve over time.
- Agents should include detailed notes explaining why code, libraries, and functions are being added.
- Do not assume a specific project build system until explicit project metadata is added.
